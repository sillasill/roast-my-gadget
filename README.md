treats standing up like an Olympic event.

Entry for the make.fun bounty
[One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

## How it works

`main.ts` (Node, standard library only, no network) writes a single
133-character roast to `/output/entry.txt`, after checking the line is
1–200 characters of non-whitespace text.

```sh
node main.ts
cat /output/entry.txt
```
